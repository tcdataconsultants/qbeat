Download Qbeat for Fire TV ↓

Version 1.2.1 · Android / Fire OS APK · Personal accounts on TV · Compact player · animated picked-by introductions.

Install with Downloader

  1. Install Downloader by AFTVnews from the Fire TV app store.
  2. On Fire TV, open Settings → My Fire TV → Developer options → Install unknown apps and allow Downloader. Menu wording varies by device.
  3. In Downloader, enter https://89.167.98.40:8443/qbeat.apk?v=1.2.1 to download the APK, then select Install.
  4. Open Qbeat, enter your host PIN, and select Connect player.

If Developer options is hidden, open Settings → My Fire TV → About and select your device name seven times, then go back.

Personal playlists on the TV

Create your account and playlists at My music. On the TV, select More → Music source / accounts → Link an account. Enter the TV’s code on your phone under Link to TV. Reopen Music source to choose the paired account and playlist.

Built for a remote

Already have Qbeat? Download and install this update over the existing app. There is no need to uninstall it.

Use the direction buttons to select controls, then the centre button to activate them. The remote’s play/pause button controls playback. Select More for music source / accounts, fullscreen TV mode, Compact player, subtitles, picked-by introductions, and a saved countdown toggle. In TV mode, Menu shows or hides controls and Back returns to the normal view.

Guests scan the QR on the TV to join. Only one player should be connected at a time: close the browser player first, then wait 15 seconds before connecting the app. Updating an existing Qbeat installation keeps your host sign-in.

YouTube restrictions still apply. If a track fails, the app shows its exact error and preserves the queue so you can retry or skip it.

This APK is for Fire OS devices. It is not compatible with Vega OS models. Qbeat does not require your Google login or YouTube API key on the TV.
